Restart autoresearch?

This archives the current autoresearch trajectory and starts a new run in the same project.

  • Current trials, runtime state, working manuscript snapshots, and generated findings move under archive/restarts/.
  • User-uploaded or explicitly selected resources stay available to the new run.
  • Autoresearch-discovered, generated, or unknown resources are archived as prior-run context, not active inputs.
  • The active Trial axis starts again at Trial 1.
